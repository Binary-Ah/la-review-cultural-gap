# Demo: 개인화용 리뷰 검색/요약 — 분석 결과


생성된 플롯은 `outputs/plots/`에 있습니다. 주요 인사이트:
- 특정 업종에서 `spice`/`oily`/`herb` 스코어가 상대적으로 높게 관찰됩니다. (top10 시각화)
- `rel_gap`(ko-en 조정 격차)와 `spicy_mean`/`oily_mean` 사이의 상관관계를 확인해, 특정 맛 프로파일이 한국인 평점에 미치는 영향을 검토할 수 있습니다.
- 언어별 t-SNE 시각화는 `ko/en/other` 리뷰가 의미 공간에서 어느 정도 분리되는지를 보여주어, 텍스트 기반 ML이 경계 사례를 포착할 타당성을 시각적으로 제공합니다.
